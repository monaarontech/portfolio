## 🌟 Overview

A modern, cinematic developer portfolio engineered with **Next.js 14**, **React 18**, **TypeScript**, and **Tailwind CSS**. Built specifically to showcase **One Palayan-Kalinga Hub** (municipal social welfare enterprise system for CSWDO Palayan City) and verified production software architectures.

### 🎯 Key Highlights

- **Flagship Capstone Showcase (`One Palayan-Kalinga Hub`)**: In-depth case study with authentic screenshots, relational schema breakdown (3NF), ISO/IEC 25010:2023 quality evaluation standards, and direct GitHub repository links.
- **Cinematic Media Lab**: Custom-engineered HTML5 9:16 mobile device video player with scrub timeline, variable playback speed (0.5x - 1.5x), and mute/unmute accessible controls.
- **Verified Software Gallery**: Real projects including the Two-Factor OTP & Auth Engine, Computer Lab Session Monitor, Pygame Game Engines, and Java Relational Database GUI client.
- **Verified Skills Matrix**: Factual categorization across Frontend, Backend, Databases, Languages, and Quality Methodologies with live search and filter controls.
- **Responsive & Accessible**: Strict color contrast, semantic HTML5, zero cumulative layout shift (CLS), and full support for `prefers-reduced-motion`.

## 🚀 Getting Started Locally

### Prerequisites

- Node.js 18+ (tested on Node.js 22 LTS)
- npm 9+

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/monaarontech/lively-mendeleev.git

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

## 🌐 Vercel Deployment Instructions

Deploying this portfolio to Vercel takes less than 2 minutes:

### Option A: One-Click GitHub Import (Recommended)

1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: complete creative personal portfolio with Palayan Kalinga Hub showcase"
   git push origin master
   ```
2. Navigate to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** -> **"Project"**.
4. Select your portfolio repository from the list.
5. In the configuration settings:
   - **Framework Preset**: Next.js (automatically detected)
   - **Root Directory**: `./`
   - **Build Command**: `npm run build`
   - **Output Directory**: `.next`
6. Click **"Deploy"**. Vercel will build and assign a global production URL (e.g. `https://mon-aaron-marcelo.vercel.app`).

### Option B: Vercel CLI

```bash
npm i -g vercel
vercel
```

Follow the command-line prompts to link and deploy.
